## English

Maccy Capture 2.9.0 is a stable release of the unofficial fork of [p0deje/Maccy](https://github.com/p0deje/Maccy).

### Changes

- Region selection freezes the screen when it starts, so copy, pin and edit use exactly what you saw. Hovering detects the element under the pointer, and a click selects it.
- The selection frame is drawn in red and shows the pointer's pixel position while dragging. The default capture shortcuts are now F1 and F3.
- New mosaic and eraser annotation tools. Pinned screenshots open at the captured region size.
- Liquid Glass is used across the app on macOS 26 and later, with a glass transparency setting for clear glass.
- The history preview formats and validates JSON. Copied JSON keeps its indentation as monospaced rich text.
- Clipboard history stays open while you take a screenshot. Selection no longer cancels when an app launch resizes the Dock.
- The app asks for Accessibility permission when automatic paste is not allowed, and checks for updates automatically while running.
- Clipboard, history and screenshot export are more robust and faster.

### Download and install

- Requires macOS 14 or later. The same ZIP and DMG support Apple silicon and Intel Macs.
- Download either package, extract or open it, then move `Maccy Capture.app` to Applications. If you already use Maccy Capture, check for updates on the Stable channel.
- Verify downloads with `SHA256SUMS.txt`. `BUILD-INFO.txt` records the build details.
- The app is signed with a fixed self-signed certificate, not Developer ID signed or Apple-notarized. macOS may block the first launch. Updating from 2.8.1, which was ad-hoc signed, may require granting screen recording and Accessibility permission again. The update ZIP has a separate Ed25519 signature.

## 简体中文

Maccy Capture 2.9.0 是基于 [p0deje/Maccy](https://github.com/p0deje/Maccy) 的非官方修改版的稳定版本。

### 更新内容

- 区域截图开始时会冻结屏幕，复制、贴屏和编辑都使用所见画面。悬停时自动识别指针下的元素，单击即可选中。
- 选框改为红色，拖动时显示指针的像素位置。默认截图快捷键改为 F1 和 F3。
- 新增马赛克和橡皮擦标注工具。贴屏截图按截取区域的大小打开。
- 在 macOS 26 及以上版本，全应用使用 Liquid Glass，并新增玻璃透明度设置。
- 历史预览可格式化并校验 JSON。复制的 JSON 以等宽富文本保留缩进。
- 截图时剪贴板历史窗口保持打开。应用启动导致程序坞尺寸变化时，选区不再被取消。
- 不允许自动粘贴时会请求辅助功能权限；运行期间自动检查更新。
- 剪贴板、历史和截图导出更稳定、更快。

### 下载与安装

- 支持 macOS 14 或更高版本。ZIP 和 DMG 均为通用包，适用于 Apple 芯片和 Intel Mac。
- 下载任一安装包，解压或打开后将 `Maccy Capture.app` 移到「应用程序」。如果已安装，可在应用内选择「稳定版」并检查更新。
- 使用 `SHA256SUMS.txt` 校验下载；`BUILD-INFO.txt` 记录构建信息。
- 应用使用固定的自签名证书签名，未使用 Developer ID 签名，也未通过 Apple 公证。macOS 可能拦截首次启动。从 Ad Hoc 签名的 2.8.1 更新后，可能需要重新授予屏幕录制和辅助功能权限。 更新 ZIP 有独立的 Ed25519 签名。
