## English

Maccy Capture 2.10.0 is a stable release of the unofficial fork of [p0deje/Maccy](https://github.com/p0deje/Maccy).

### Changes

- Long screenshot: region capture can scroll and stitch a capture taller than the screen.
- New numbered marker and magnifier annotation tools. Finished annotations can be selected, moved, resized with handles and deleted, each as one undo step. Settings lists the annotation tools to reorder them and turn each on or off.
- The frozen screen keeps window shadows and matches the live screen, and region selection opens faster.
- The screenshot thumbnail preview moved to the bottom left.
- Settings > Appearance > Liquid Glass has a Glass style choice: Frosted (the new default) or Clear.
- The Test channel reads each test build's own release, so it can update again.

### Download and install

- Requires macOS 14 or later. The same ZIP and DMG support Apple silicon and Intel Macs.
- Download either package, extract or open it, then move `Maccy Capture.app` to Applications. If you already use Maccy Capture, check for updates on the Stable channel.
- Verify downloads with `SHA256SUMS.txt`. `BUILD-INFO.txt` records the build details.
- The app is signed with a fixed self-signed certificate, not Developer ID signed or Apple-notarized. macOS may block the first launch. Updating from a build with a different signature may require granting screen recording and Accessibility permission again. The update ZIP has a separate Ed25519 signature.

## 简体中文

Maccy Capture 2.10.0 是基于 [p0deje/Maccy](https://github.com/p0deje/Maccy) 的非官方修改版的稳定版本。

### 更新内容

- 长截图：区域截图可滚动并拼接超出屏幕高度的内容。
- 新增序号标记和放大镜标注工具。完成的标注可选中、移动、拖动控制点调整大小和删除，每次操作可单独撤销。设置中列出标注工具，可调整顺序并单独开关。
- 冻结的屏幕画面保留窗口阴影，与实际屏幕一致；区域选择打开更快。
- 截图缩略图预览移到左下角。
- 「设置 > 外观 > Liquid Glass」新增玻璃样式选项：磨砂（新默认）或透明。
- 测试版通道读取每个测试构建各自的发布，恢复可用。

### 下载与安装

- 支持 macOS 14 或更高版本。ZIP 和 DMG 均为通用包，适用于 Apple 芯片和 Intel Mac。
- 下载任一安装包，解压或打开后将 `Maccy Capture.app` 移到「应用程序」。如果已安装，可在应用内选择「稳定版」并检查更新。
- 使用 `SHA256SUMS.txt` 校验下载；`BUILD-INFO.txt` 记录构建信息。
- 应用使用固定的自签名证书签名，未使用 Developer ID 签名，也未通过 Apple 公证。macOS 可能拦截首次启动。从签名不同的版本更新后，可能需要重新授予屏幕录制和辅助功能权限。更新 ZIP 有独立的 Ed25519 签名。
